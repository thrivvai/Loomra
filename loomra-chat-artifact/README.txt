Loomra Chat - Static HTML Artifact
==================================

This folder is ready to upload to Netlify.

Netlify upload options:
1. Drag and drop this entire folder into Netlify's manual deploy area.
2. Or upload the included index.html file as the site's root index.html.

After deployment:
1. Open the site.
2. Click Settings.
3. Paste your OpenRouter API key.
4. Choose or load a free OpenRouter model.
5. Save settings and start chatting.

Privacy/security note:
This is a private, browser-only static app. Your OpenRouter key and chats are stored in this browser's localStorage. Do not hard-code your API key into index.html before uploading it.
